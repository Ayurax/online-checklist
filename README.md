## What it does

- Create tasks and break them into subtasks.
- Track completion with progress indicators.
- Move between To Do, Completed, and Trash.
- Restore deleted tasks or remove them permanently.
- Save tasks automatically in your browser.
- Use it without creating an account.

## Run it locally

1. Clone this repository.
2. Open `index.html` in your browser.

That's it. No install, no build step, and no framework with more layers than your laundry pile.

## Data and privacy

Tasks stay in your browser's local storage on that device. There is no cloud account or automatic sync between devices. Clear browser storage and your tasks may vanish into the quantum void.
